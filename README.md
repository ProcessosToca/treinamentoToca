# Projeto Estoque Toca

Plataforma de estudo do aprendiz da Toca Imóveis: aulas do Curso em Vídeo (Gustavo Guanabara), passos guiados, tutor ChatGPT e painel de progresso.

- Tudo está em `index.html` (sem banco de dados, sem build).
- Logo: salve como `logo.png` na mesma pasta do `index.html`.
- Progresso: salvo no navegador do aprendiz. No **Painel** há "baixar cópia" e "restaurar" para continuar de onde parou em outro dia ou computador.
- Para editar aulas e passos, altere a lista `FASES` no começo do script.
- Publicação: qualquer hospedagem estática (Vercel, GitHub Pages). Os vídeos só tocam dentro da página quando ela abre por endereço web.
